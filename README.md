# NEPSE Invest

Web research desk for Nepal Stock Exchange names. Scores companies on earnings quality, capital, dividends, and governance, then layers a transparent 20-session price model.

```bash
export PATH="$HOME/.local/bin:$PATH"   # if node lives in ~/.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Figures in `src/lib/data/companies.ts` are a research snapshot, not a live NEPSE feed. Not investment advice.
